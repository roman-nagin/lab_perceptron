# Perceptron Lab

Однослойный перцептрон с нуля на Python для бинарной классификации.

## Что такое перцептрон

Линейный бинарный классификатор. Принимает вектор признаков, считает
взвешенную сумму, сравнивает с порогом и выдаёт `0` или `1`:

```
z = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b
pred = 1, если z ≥ 0
pred = 0, если z < 0
```

Геометрически это **прямая** (в 2D), которая разделяет два класса.
Уравнение границы: `w₁·x₁ + w₂·x₂ + b = 0`.

## Как обучается

1. Веса `w` и смещение `b` стартуют с нуля.
2. Для каждого объекта `(x, target)`:
   - считаем `pred = activate(w·x + b)`;
   - `error = target − pred`;
   - если `error ≠ 0`:
     ```
     wᵢ ← wᵢ + learning_rate · error · xᵢ
     b  ← b  + learning_rate · error
     ```
3. Один проход по всем объектам = **эпоха**. Обычно хватает 10–100 эпох.
4. Если за эпоху ошибок нет — сошлись, дальше учить не нужно.

**Теорема Розенблатта:** если данные линейно разделимы, перцептрон
гарантированно сойдётся за конечное число шагов.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate      # macOS/Linux
pip install -e ".[dev]"
```

## Запуск

```bash
python -m perceptron --samples 200 --lr 0.1 --epochs 50
```

Флаги:

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--samples` | 200 | число точек |
| `--lr` | 0.1 | learning rate |
| `--epochs` | 50 | эпох обучения |
| `--seed` | 42 | воспроизводимость |
| `--no-plot` | — | не сохранять графики |
| `--iris` | — | дополнительно обучиться на iris |

Пример вывода:

```
Perceptron trained on 200 samples
Final accuracy: 1.000
Weights: [0.87, 0.75], bias: -0.1
```

Графики сохраняются в `plots/`: граница решения и кривая ошибок по эпохам.

## Ограничения

- Только **линейно разделимые** данные (XOR не решает).
- Только **два класса**.
- Нет «уверенности» в предсказании — только `0/1`.
